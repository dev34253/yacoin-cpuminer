# Project board: Yacoin CPU miner

- [`plans/plan.md`](plans/plan.md) – the plan (goal, scope, facts from the
  node code, design, tests, risks).
- `todo/` – tasks not started; `inprogress/` – being worked on; `done/` – finished.
- [`open-questions.md`](open-questions.md) – decisions for the owner.

Task files: `T-<nn>-<slug>.md` with Depends on, Size (S < 1 day, M = a few
days), Owner, Started, Finished, Goal, Steps, Acceptance criteria, Log. Move
them with `git mv` todo → inprogress → done.
